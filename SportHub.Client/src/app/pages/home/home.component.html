Three ways to book

Each is priced differently, and SportHub calculates it — never guessed at the counter.

01

Reserve a facility

Pick a court or field, a day, and a run of 30-minute blocks up to six hours. Blocks another booking already holds cannot be crossed, so a double booking is not possible.

Hourly rate × duration
02

Rent equipment

Rent gear on its own for a day. Choose a pickup time and the return is set to the same time the next day. Quantities are checked against the rentals already on the books.

Daily price × quantity
03

Build a package

Combine one facility with the gear you need for the same time. The equipment follows the facility booking exactly — pick it up when you arrive, return it when you finish.

Facility + gear per hour
